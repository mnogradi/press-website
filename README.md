# Aurora Fidelis Press

**Bringing the Ancient Dawn to the Modern Mind**

A professional website for Aurora Fidelis Press, a classical Christian literature publishing house specializing in high school curriculum and poetry collections.

## 🌅 About

Aurora Fidelis Press is committed to the "Defoe Standard" of quality, preserving the ancient dawn of Christian thought and English literary mastery for the next generation of scholars and poets.

## 📚 Collections

### The Borealis Collection
A rigorous, four-year logical progression through the pillars of Christian and English literature, designed for the classical homeschool.

- **9th Grade**: Introduction to Christian Literature
- **10th Grade**: World Literature
- **11th Grade**: Advanced Christian Literature
- **12th Grade**: English Literature

### The Astralis Collection
Lyric wisdom for all ages - from the intricate "High Art" of George Herbert to the whimsical rhymes of Eugene Field.

### The Aurora Archive
Speeches, prayers, and letters from the giants of the faith.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/aurora-fidelis.git
   ```

2. Open `index.html` in your browser:
   ```bash
   cd aurora-fidelis
   start index.html  # Windows
   open index.html   # macOS
   xdg-open index.html  # Linux
   ```

   Or use a local server (recommended):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (npx)
   npx serve
   ```

3. Visit `http://localhost:8000` in your browser
